# CE-25A 设备数据库 — 导入指南

## 数据库结构

```
设备 (主表, 宽表)
│  设备名称 ← 主键
│  62 列: 基础信息 + 托架 + 电搭接 + 设备架接口 + 温度鉴定 + 重量 + 惯量
│
├──< 负载电气特性 (子表)
│     负载ID ← 主键
│     设备名称 → 设备.设备名称
│     一个设备可有多条 (不同电压等级 + 不同功能通道)
│
├──< 负载工作模式 (子表)
│     负载ID + 工作模式 ← 复合主键
│     设备名称 → 设备.设备名称
│     G0~G8 飞行阶段 0/1 矩阵
│
└──  飞行阶段定义 (维度表)
      阶段编号 ← 主键 (G0~G8)
      含同时系数等人工输入参数
```

## X号构型导入记录

以下是本次导入的完整步骤，后续导入其他构型（1&2号、0号等）时参照执行。

---

### 步骤 1：导入主表基础数据

**来源**: `机载系统设备清单_2026.0415.xlsx` → 对应构型的 sheet

**操作**:
1. 清空数据库 (如需全新导入)
2. 以 **设备名称** 为主键 (Unique ID) 导入
3. 列名清理: 去换行符，保留主名称
4. 设备名称为 "TBD" 的编号为 TBD_1, TBD_2...
5. 所有字段暂时都作为属性列导入

**注意事项**:
- 设备名称必须唯一，检查重复
- X号构型仅 2 个 TBD 名称，其他构型可能不同

---

### 步骤 2：导入托架信息

**来源**: `机载系统设备清单_2026.0415.xlsx` → `托架信息` sheet

**操作**:
1. 以 K列 (对应设备) 匹配主表的设备名称
2. 匹配上的写入主表新增列: 托架名称、锁紧器、特殊需求(托架)、是否158提供、设备布置区域(托架)
3. 名称不匹配的手动映射 (如 交通监视处理机→T3CAS处理机, 5G ATG机载CPE→5G机载CPE)
4. 匹配不上的跳过，记录到 `未录入数据.md`

**X号构型结果**: 26 匹配 / 5 跳过

---

### 步骤 3：导入设备架接口信息

**来源**: `机载系统设备清单_2026.0415.xlsx` → `设备架接口信息` sheet

**操作**:
1. 以 设备名称 匹配主表
2. 同时导入 "左前设备架设备清单" 列 (类似LIN号)
3. 匹配上的写入主表新增列: 布置位置(设备架)、左前设备架设备清单、安装方式(设备架)、电搭接方式(设备架)、重量kg(设备架)、备注(设备架)
4. 名称匹配但LIN不一致的照常导入 (仅按设备名称匹配)
5. 匹配不上的跳过记录

**X号构型结果**: 57 匹配 / 11 跳过

---

### 步骤 4：导入电搭接情况统计

**来源**: `机载系统设备清单_2026.0415.xlsx` → `电搭接情况统计` sheet

**操作**:
1. 以 B列 (设备名称) 匹配主表
2. 匹配上的写入主表新增列: 设备安装图、是否首飞上机、电搭接形式、电搭接类型(统计)、电搭接阻值要求(mΩ)、搭接位置、是否已在PACE图纸中体现、电搭接备注
3. 不做模糊匹配/名称映射，严格按设备名称匹配
4. 匹配不上的跳过记录

**X号构型结果**: 319 匹配 / 103 跳过

**未匹配较多的原因**: 电搭接表包含管路、传感器、光纤等非X号构型设备

---

### 步骤 5：导入负载电气特性

**来源**: `飞机负载统计表-XX号机-XXXX发电源.xlsx` → `负载电气特性` sheet

**操作**:
1. 表头在第 2 行 (header=1)
2. 以 **负载ID** 为主键建子表（不是设备名称，因为同一设备有多条负载记录）
3. 以 设备名称 关联主表
4. 匹配不上的跳过记录

**注意事项**:
- 同一设备可有多个负载ID (不同电压 28V/270V/800V，不同功能通道 加热/控制)
- 负载ID 格式: `LIN号-电压-功能`，如 `3403U2501-28V-加热`
- 不同构型的负载统计表是不同的文件

**X号构型结果**: 158 导入 / 39 跳过

---

### 步骤 6：导入飞行阶段定义 + 负载工作模式

**来源**: `飞机负载统计表-XX号机-XXXX发电源.xlsx` → `负载统计飞行阶段定义` + `负载工作模式` + `负载统计`

**操作**:

#### 6a. 飞行阶段定义表
- 维度表，G0~G8 共 9 个阶段
- 直接导入，含阶段名称、时长、定义、舵面、速度、高度
- 注意合并行结构（Excel 有子行需手动解析）

#### 6b. 从负载统计表提取人工参数
- `负载统计` sheet 中大部分是公式计算量，**不入库**
- 仅提取 3 列人工输入数据写入飞行阶段定义表:
  - 峰值最大功率同时系数
  - 应急最大功率同时系数
  - 270V主要功率来源

#### 6c. 负载工作模式子表
- 以 **负载ID + 工作模式** 为复合主键
- 38 列中只导入前 20 列 (基础信息 + G0~G8 的 0/1 矩阵)
- **不导入**: 列 20~28 (正常功率计算辅助列)、列 29~37 (电量计算辅助列) — 均为公式推导
- 工作模式包括: 工作、关闭、待机、应急、发射、打开、最大功率、额定功率等

**X号构型结果**: 飞行阶段 9 行 / 负载工作模式 340 导入, 79 跳过

---

### 步骤 7：导入温度鉴定数据

**来源**: `CE-25A飞机0号机有人首飞机载系统设备清单_0417—温度.xlsx`

**操作**:
1. 表头在第 2 行 (header=1)
2. 以 设备名称 匹配主表
3. 匹配上的写入主表新增 12 列温度属性
4. 跳过主表已有的重复字段 (系统名称、设备编号、LIN号、设备布置区域)
5. 匹配不上的跳过记录

**导入的列**: 首飞是否上机、二阶段是否上机、设计要求等级、要求等级对应温度、DO-160温度高度鉴定等级、鉴定工作温度范围、鉴定符合情况、正常工作温度(℃)、短时工作温度(℃)、地面停放温度(℃)、高度(m)、鉴定报告编号

**注意**: `温度.xlsx` 和 `温度-汇总V1.xlsx` 内容完全一致，导入任一即可

**X号构型结果**: 357 匹配 / 64 跳过

---

### 步骤 8：导入重量数据

**来源**: `重量表单模板.xlsx`

**操作**:
1. 多层表头，手动指定列名
2. 以 设备名称 匹配主表
3. **实测重量覆盖**主表已有的「重量(kg)」列
4. 新增列: 重量指标、超重风险、重心X/Y/Z(mm)、Ix/Iy/Iz/Ixy/Ixz/Iyz(kg*m2)
5. 全空列也建列（惯量列当前全空，预留后续填充）

**注意**: 导入前先对比实测重量与主表已有重量(kg)的差异，确认覆盖策略

**X号构型结果**: 361 匹配 (331 重量覆盖) / 43 跳过

## 跳过数据记录

所有跳过项记录在 `未录入数据.md` 中，格式:
- 文件名 / Sheet名 → 导入目标
- 导入时间、写入数、跳过数
- 跳过设备清单表格 (设备名称、系统、跳过理由)

**跳过的主要原因**:
1. 设备名称在主表中不存在 (其他构型独有设备)
2. 设备名称写法不同 (如 `涵道风扇1` vs `涵道风扇1（金属）`、`构型B动力电池1` vs `构型B动力电池（含BMS与继电器开关）1`)

## 导入新构型的操作清单

```
□ 1. 清空数据库
□ 2. 导入主表 (对应构型 sheet, 设备名称为主键)
□ 3. 导入托架信息 (K列匹配设备名称)
□ 4. 导入设备架接口信息 (设备名称匹配)
□ 5. 导入电搭接情况统计 (B列匹配设备名称)
□ 6. 导入负载电气特性 (负载ID主键, 设备名称关联)
□ 7. 导入飞行阶段定义 + 负载工作模式 + 负载统计人工参数
□ 8. 导入温度鉴定 (设备名称匹配)
□ 9. 导入重量数据 (设备名称匹配, 实测重量覆盖)
□ 10. 检查 未录入数据.md 中的跳过项
```
