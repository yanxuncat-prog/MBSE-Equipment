# 设备库页面重构设计规格

## 概述

重构设备库页面，支持多层级筛选和双视角浏览。

## 页面结构

三层水平栏 + 内容区：

```
┌─ 顶栏 ─────────────────────────────────────────────────┐
│ 🗄 设备库清单  267种   型号:[CE-25A▾]  [📋表单|🃏卡片] │
├─ 筛选栏 ───────────────────────────────────────────────┤
│ ATA:[全部章节▾多选]  状态:[全部|待确认|已入库]  [批量确认]│
├─ 属性TAB (仅表单视角) ────────────────────────────────┤
│ [标识与分类][物理特性][电气特性][接地与搭接][机械接口]    │
├─ 内容区 ──────────────────────────────────────────────┤
│ 表单视角: 带列头搜索的数据表格                           │
│ 卡片视角: 缩略卡片网格 / 点击展开详情大卡片              │
└──────────────────────────────────────────────────────┘
```

## 层级控件

### 1. 型号选择
- 下拉选择器，数据来自 `programs` 表
- 当前只有 CE-25A，但支持多型号扩展
- 切换型号后重新加载该型号下的设备库数据

### 2. 视角切换
- 两个按钮组：「表单」和「卡片」
- 表单视角：数据表格，带列头搜索和属性分组TAB
- 卡片视角：设备卡片网格，无属性TAB（卡片内已分组展示）

### 3. ATA 多选下拉
- 下拉多选，可同时勾选多个 ATA 章节
- 选项从当前设备库数据中动态提取（只显示有设备的 ATA）
- 默认全选

### 4. 状态筛选
- Tab 形式：全部 / 待确认(Draft) / 已入库(Valid)
- 显示各状态的数量

### 5. 属性分组TAB（仅表单视角）
- 5 个分组，切换后表格显示对应列
- 每组始终保留「件号」和「设备类型名称」作为锚定列

## 表单视角

### 列头搜索
- 表头下方增加一行搜索输入框
- 只对文本类列提供搜索（件号、名称、供应商件号、描述等）
- 布尔、数值列不提供搜索框
- 搜索为前端即时过滤（已全量加载）

### 5 个属性分组的列

**标识与分类：** 件号、设备类型名称、英文名称、英文缩写、ATA、类型、DAL、供应商件号、描述

**物理特性：** 件号、设备类型名称、尺寸、连接器数量、金属壳体、壳体不导电处理

**电气特性：** 件号、设备类型名称、电设备、一级用电、EICD、供电电压、电压范围、供电余度、用电功率、正常功耗、应急功耗、峰值功耗、软启动、峰值时间、异类供电、应急可卸

**接地与搭接：** 件号、设备类型名称、内部共地、壳体接地方式、故障电流路径、接地特殊要求、接地端子内径、搭接方式、搭接类型、搭接阻值

**机械接口：** 件号、设备类型名称、螺钉牌号、托架委托158、公差工程图

## 卡片视角

### 网格浏览
- 3~4 列卡片网格（响应式）
- 每张缩略卡片显示：
  - 设备类型名称（标题）
  - 件号（副标题，等宽字体）
  - 状态标签（Draft 橙色 / Valid 绿色）
  - 4 个关键属性（ATA、类型、电压、功耗）
  - 属性完成度百分比条

### 展开详情
- 点击缩略卡片展开为完整大卡片
- 大卡片按 5 个属性分组显示所有字段
- 每组用不同颜色标识：
  - 标识与分类：默认色
  - 物理特性：蓝色 📐
  - 电气特性：琥珀色 ⚡
  - 接地与搭接：绿色 🔌
  - 机械接口：紫色 🔧
- 未填写的字段显示为灰色「未填写」
- 每个属性旁有 ⓘ 图标，点击弹出知识面板

### 知识面板
- 点击 ⓘ 弹出属性说明
- 内容包含：属性定义、取值范围/含义、相关标准参考
- 内容预置在前端代码中（静态知识库）
- 后续扩展：设备连接关系属性类型（从外部网站拉取）

## 后端 API 变更

### GET /api/equipment-library
新增参数：
- `program_id` (string, optional) — 按型号筛选
- `ata_chapters` (string, optional) — 逗号分隔的 ATA 列表，多选筛选

已有参数保持不变：`search`、`library_status`、`offset`、`limit`

### 数据模型
- `equipment.library_status` 字段已存在（draft/valid）
- 设备库与型号的关联：当前 equipment 表没有 program_id。设备库是全局的，但可通过 `ata_chapter` 所属型号间接关联。若需直接关联，在 equipment 表加 `program_id` FK。
